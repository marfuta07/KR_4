## Курсовая работа: Сервис управления рассылками

### Часть 1: Разработка сервиса
- Управление клиентами (`Recipient` + CRUD)
- Управление сообщениями (`Message` + CRUD)
- Управление рассылками (`Mailing` + CRUD + `update_status()`)
- Отправка рассылок (`send_mailing` + batch через `bulk_create`)
- Попытки рассылок (`MailingAttempt`)
- Главная страница со статистикой

### Часть 2: Расширение функциональности
- Аутентификация (регистрация, вход, выход, восстановление пароля)
- Статистика (личная / общая для менеджера)
- Ограничение доступа (роли, `owner`, блокировка пользователей, отключение рассылок)
- Кеширование (Redis + `Cache-Control` middleware)

### Технологии
Django 6.1, PostgreSQL, Redis, Poetry, Bootstrap 5, python-dotenv
